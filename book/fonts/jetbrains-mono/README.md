# JetBrains Mono, self-hosted

JetBrains Mono, Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono),
licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org).

The latin and latin-ext subsets of the regular face, from Google Fonts' static files, as spwashi.com carries them
(public/fonts, 2026-08-18). Self-hosted so a page's text never waits on a third-party CDN; declared in
book/styles/core/fonts.css, where what the subsets lack (arrows, boxes, shapes) still comes from the CDN, and
only when a page uses it.
